Review the protocol implementation or proposal.

Cover:

- State machine.
- Handshake.
- Session lifecycle.
- Framing.
- Partial I/O.
- Streaming.
- Backpressure.
- Timeouts.
- Keepalive.
- Authentication.
- Encryption.
- Retries.
- Duplicates.
- Idempotency.
- Ordering.
- Resource limits.
- Shutdown.
- Proxy and tunnel effects.
- Error translation.

Explicitly distinguish FTP, FTPS, SFTP, SSH, WebSocket and gRPC semantics.
