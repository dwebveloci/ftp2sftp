---
name: review-architecture
description: Reviews a proposed or implemented design for architectural consistency.
---

Review architecture without editing files.

Evaluate:

- Boundaries.
- Dependency direction.
- Domain leakage.
- Transaction scope.
- Synchronous versus asynchronous communication.
- Coupling.
- Failure containment.
- Scalability.
- Operability.
- Security.
- Deployment.
- Migration complexity.
- Simpler alternatives.

Return findings by severity and a final recommendation:
approve, approve-with-changes or redesign.
