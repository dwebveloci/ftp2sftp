name: prepare-deployment
description: Produces a production-readiness plan for a backend service.
---

Prepare the service for deployment.

Inspect:

- Build and runtime artifact.
- Container configuration.
- User and filesystem permissions.
- Configuration validation.
- Secrets.
- Network exposure.
- Proxy or tunnel.
- Health and readiness.
- Graceful shutdown.
- Persistent storage.
- Migrations.
- Backup and recovery.
- Resource limits.
- Scaling.
- Logs, metrics and traces.
- Rollback.

Return:

- Blockers.
- Required changes.
- Deployment sequence.
- Verification.
- Rollback.
- Operational runbook checklist.

Do not edit unless explicitly requested.
