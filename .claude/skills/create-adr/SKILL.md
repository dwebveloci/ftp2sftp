---
name: create-adr
description: Creates a concise Architecture Decision Record.
---

Create an ADR for the selected decision.

Use:

- Title.
- Status.
- Date.
- Context.
- Decision.
- Alternatives considered.
- Consequences.
- Security consequences.
- Operational consequences.
- Migration or rollback.
- Follow-up actions.

Do not turn the ADR into a technology tutorial.
Use project-specific facts and explicit assumptions.
